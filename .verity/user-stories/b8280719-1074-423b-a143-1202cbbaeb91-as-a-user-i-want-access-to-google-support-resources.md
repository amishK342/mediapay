## Description

A general user needs to access Google support resources to resolve issues or get help with Google products or services. Providing easy access to Google support ensures users can quickly find solutions to their problems, improving user satisfaction and reducing frustration. The support access should be clear, easy to find, and direct users to official Google support channels.

## Acceptance Criteria

- [ ] Given a user is on the support page, When they look for Google support, Then they should see a clearly labeled link or button for Google support resources.
- [ ] Given a user clicks the Google support link, When the link is activated, Then the user should be redirected to the official Google support website.
- [ ] Given a user is seeking help, When they access the support section, Then they should find information about what types of issues Google support can help with.
